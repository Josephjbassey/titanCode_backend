# 📊 TitanCode Technologies: PM Guide (Unified Manual Model)

This guide explains the "Zero-Friction" business model implemented for TitanCode.

---

## 1. Role Matrix (Simplified)

| Role | Responsibility |
| :--- | :--- |
| **CEO/Admin** | Financial settlement and oversight. |
| **HR** | Lead capture and manual client relationship management. |
| **Manager** | Internal project architecture and team assignment. |
| **Member** | Technical execution and delivery. |

---

## 2. Conversion Optimization: The Unified Form

We have scrapped the separate "Sign Up" and "Hire Us" buttons. There is now only **one call to action**.

### **Technical Magic Behind the Form**
When a client clicks "Submit" on the Hire Us form:
1.  **Lead Capture**: The project request is saved.
2.  **Shadow Account**: The system creates a user record for the client automatically. This ensures that when the client eventually pays, the money is correctly associated with their "Account" for internal accounting and the 70/30 split.
3.  **No Login Required**: The client never needs to remember a password or log in. HR handles everything via WhatsApp/Email.

---

## 3. Communication Strategy (The "Concierge" Model)

1.  **Inbound Lead**: HR gets an email: "🔥 NEW LEAD: [Project Name]".
2.  **WhatsApp Outreach**: HR clicks the phone number in the lead email to start a WhatsApp chat.
3.  **Human Verification**: HR confirms the budget and hands off the lead to a Department Manager.
4.  **Internal Tracking**: The Manager uses the TitanCode dashboard to track tasks. The client stays in the loop via WhatsApp.

---

## 4. Financial "Safety Net"
*   **Stripe Integration**: Even though onboarding is manual, payments are automated.
*   **70/30 Split**: The system ensures every developer gets paid exactly their share without any manual calculation needed from the PM.
